# Gravity Flip Runner

A fun endless runner game built using **HTML**, **CSS**, and **JavaScript**.

# Features
 Gravity Flip (Space Key)
 Alternating Obstacles
 Coin Collection
Increasing Speed
 High Score Saving
 Game Over & Restart
 Responsive Design

# Controls
 Space → Flip Gravity
 R → Restart Game

# How to Play
 
 Press **Space** to flip between the floor and ceiling.
 Avoid red obstacles and collect coins.
 Try to beat your high score.
